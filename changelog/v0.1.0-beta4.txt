FLOW DESKTOP CHANGE LOG
VERSION: 0.1.0-beta4
DATE: 2026-10-28
STATUS: PRE-RELEASE

ABOUT
Flow Desktop is a privacy-first YouTube and YouTube Music client - no account, no ads, no analytics, no telemetry. It is the desktop companion to Flow for Android.

PROFILES
- Up to five profiles on one computer, each with its own recommendations, history, library and settings, so a study profile and a gaming profile never mix. Downloads are shared.
- Switch from your avatar in the top bar or in Settings > Profiles. Switching restarts Flow, and the new profile opens in its own theme.
- A new profile starts fresh with a short setup, or copies your settings, subscriptions or recommendations. Profiles are not locked: anyone using the computer can switch.
- Only the Default profile syncs with your phone. A master backup now holds every profile and restores them all.
- The recommendation engine's profile is now called your taste profile.

SYNC
- Your recommendations sync with Flow for Android again. Both apps now read Chinese titles the same way, folding Traditional characters into Simplified ones.
- When something stays on each device, the sync result now says what and why. After receiving, it lists what arrived.
- SponsorBlock's action for each segment type now syncs with your phone. Synced SponsorBlock and DeArrow switches apply without a restart.
- Data synced before comes back if this computer lost it. Music playlists from your phone no longer return under a new name, history sent to the phone has thumbnails, and subscription groups are sent when Flow Desktop scans the phone's code.
- Play on: moving playback between Flow Desktop and your phone works again. A phone that paused or stopped no longer stays listed as playing, and a phone at full volume no longer shows its volume at 0.
- Play on: picking a device now works as on Android. This computer takes playback back from the device you control, picking another device moves that device's session there, and a device that stops answering stops showing as playing.
- Linked devices: choose which profiles sync. A profile starts its own synced profile or joins one from your other devices, and Profiles under Linked devices adds one that only your other devices have.
- A synced profile that isn't open keeps what arrives and catches up when you switch to it. Stopping a profile on every device keeps its data on each one.
- Linked devices has a Dashboard: where the group lives, how much of a Flow server's storage it uses, your devices, each synced profile's state and the latest sync errors.
- The Flow Neuro page can show the interests of your other synced profiles, read on this computer without switching. From the Dashboard, View interests opens them.
- A sync that arrives while Flow is busy saving something else, such as right after switching profiles, no longer fails and has to be run again.
- A new device's Default profile now syncs only with Default here. If Default doesn't sync on this computer, the new device's Default starts its own synced profile instead of merging into another one.
- On the local network, a device list entry from another device that can't be read is skipped, and the rest of the list still syncs.
- Linked devices: a device name that can't be read is left out instead of hiding the device list or stopping a rename. The latest readable name is shown.
- A snapshot, acknowledgement or LAN request that names a log position too large to read exactly is now refused as invalid.
- A damaged file in a WebDAV folder's roster no longer stops every device from syncing. It is skipped and the rest of the roster is read.
- Sync no longer hangs on a store that keeps answering with the same page. It stops reading and tries again at the next sync.
- Sync stops reading an answer larger than it can be, from a Flow server, a WebDAV folder, the live channel or a device on your network, so a broken or hostile store can't use up memory.
- A damaged or forged object from one device no longer fails the whole sync. Reading that device's changes pauses there, and the other devices' changes still arrive.
- The same holds when a new device starts from a snapshot or a profile starts syncing: a damaged or forged object no longer fails the sync, and the profile is caught up once it can be read.
- A snapshot or profile name from another device that carries an out-of-range number no longer stops a synced profile from being read.
- A malformed roster entry from another device on the local network is refused, so the group stays readable on this computer.
- Joining a group over the local network now refuses a malformed welcome from the other device.
- The Sync page now opens on Linked devices, which keep your devices in sync all the time. The one-time transfer to a nearby device moves below them, and Linked devices stay on screen while a transfer runs.

FIXES
- Restarting Flow after an update no longer opens the link Flow was first started with a second time.
- A restarted AppImage starts from your own environment instead of the old bundle's paths.
- Flow opens in your theme from the first frame, instead of showing the default colours for a moment.
